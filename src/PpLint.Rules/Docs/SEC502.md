# SEC502 — Endereço de ambiente fixo na fórmula

## O que pega

URL literal que identifica um ambiente ou um tenant específico: `*.crm*.dynamics.com`, `*.sharepoint.com`, `*.azurewebsites.net`, `*.logic.azure.com`.

URL pública genérica não conta — link para documentação é uso legítimo e não muda entre ambientes.

## Por que importa

O endereço não muda quando a solução é promovida. O app publicado em produção continua conversando com o ambiente de desenvolvimento: lê dados de teste, grava em tabela errada, e o problema só aparece quando alguém estranha que o registro não chegou.

Pior quando o sentido é o inverso — o app de desenvolvimento apontando para produção, gravando dados de teste na base real.

## Exemplo

Ruim:

```
Set(varApi, "https://contoso-dev.crm4.dynamics.com/api/data/v9.2")
```

Bom: uma variável de ambiente da solução, cujo valor é definido em cada ambiente na importação.

# PF121 — Referência a controle de outra tela

## O que pega

Fórmula que lê a propriedade de um controle que vive em outra tela: `lblTotal.Text` numa tela, com `lblTotal` em outra.

Referência à própria tela — `'Tela de Config'.Width` — não conta: dimensão de tela é layout e resolve sem a tela estar carregada.

## Por que importa

O valor de um controle só existe depois que a tela dele é carregada. Antes disso a leitura devolve branco, **sem dar erro**.

O resultado é um app que funciona ou não conforme o caminho que o usuário percorreu. Quem passou pela tela de configurações vê o valor certo; quem foi direto para a tela principal vê vazio, e o bug é irreprodutível para quem testou na ordem "certa".

## Exemplo

Ruim, com `sldTempo` na tela de configurações:

```
lblTempo.Text = sldTempo.Value
```

Bom: na tela de configurações, guarde o valor:

```
Set(varTempo, sldTempo.Value)
```

E leia a variável na outra tela. Melhor ainda: defina o valor padrão no `OnStart`, para que exista mesmo que ninguém abra as configurações.

# NM010 — Controle com o nome que o Studio gerou

## O que pega

Controle que ficou com o nome automático do Power Apps Studio: `Button1`, `Label7`, `Rectangle11`, `Gallery2`. São nomes com sufixo numérico e sem nenhuma informação sobre o que o controle faz.

## Por que importa

O nome do controle é referência de código: outras fórmulas escrevem `Label7.Text`. Quando o nome não diz nada, cada leitura obriga a abrir o Studio e procurar o controle na tela para descobrir do que se trata.

Pior: a numeração não é estável. Inserir ou duplicar controles renumera os que vêm depois, e `Label7` passa a ser outro — enquanto as fórmulas que o citavam continuam apontando para o nome antigo.

Controles gerados pelo próprio Studio dentro de galerias e formulários — `galleryTemplate`, `DataCard` — não são cobrados, porque ninguém os escreveu.

## Exemplo

Ruim:

```
Button1
Label7
```

Bom:

```
btnConfirmarPedido
lblTotalPedido
```

## Como configurar

Para tratar outros templates como gerados pelo Studio:

```toml
[pp-lint.naming]
generated-control-templates = ["galleryTemplate", "dataCard", "meuTemplate"]
```

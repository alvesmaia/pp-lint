# PF120 — `UpdateContext` no `App.OnStart`

## O que pega

Chamada a `UpdateContext` numa propriedade do objeto App — `OnStart` ou `OnError`.

## Por que importa

Variável de contexto pertence a uma tela. O App não é uma tela, então a chamada não define nada: não há erro, não há aviso no Studio, e quem ler a variável depois recebe branco.

O sintoma típico é uma tela que aparece vazia na primeira abertura e certa depois que o usuário navega — porque em algum momento outra fórmula, essa numa tela, definiu a variável de verdade.

## Exemplo

Ruim:

```
UpdateContext({locUsuario: User().FullName})
```

Bom:

```
Set(varUsuario, User().FullName)
```

`Set` cria variável global, que é o que faz sentido para estado definido na abertura do app.

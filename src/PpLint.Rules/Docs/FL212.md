# FL212 — Ação desabilitada

## O que pega

Ação com resultado estático ligado — `runtimeConfiguration.staticResult.staticResultOptions` igual a `Enabled`. É o que o designer chama de desabilitar a ação.

## Por que importa

A ação devolve saída simulada e **não executa**. O e-mail não é enviado, o registro não é gravado, e a execução aparece como bem-sucedida no histórico.

Quase sempre é um teste que ficou ligado: alguém desabilitou a ação para testar o resto do fluxo e não desfez. Descobrir isso costuma levar dias, porque o histórico não dá nenhum sinal.

## Exemplo

Ruim, no JSON do fluxo:

```json
"Enviar_email": {
  "type": "OpenApiConnection",
  "runtimeConfiguration": {
    "staticResult": { "name": "Enviar_email0", "staticResultOptions": "Enabled" }
  }
}
```

Bom: desligue o resultado estático nas configurações da ação, ou remova a ação se ela não é mais necessária.

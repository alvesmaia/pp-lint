# PF110 — Condição constante

## O que pega

`If` cuja condição é um literal ou uma comparação entre literais: `If(true, …)`, `If(2 > 1, …)`, `If(false, …)`.

## Por que importa

Um dos ramos nunca executa. Quase sempre é depuração esquecida — alguém fixou a condição para testar um caminho e não desfez. O código morto continua sendo lido e mantido por quem vier depois.

## Exemplo

Ruim:

```
If(true, Navigate(scrHome), Navigate(scrLogin))
```

Bom:

```
Navigate(scrHome)
```

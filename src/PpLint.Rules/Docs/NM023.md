# NM023 — Nome de exibição divergente do nome de esquema

## O que pega

Coluna cujo nome de exibição, comparado sem espaços e sem diferenciar maiúsculas, não corresponde ao nome de esquema depois do prefixo.

`gmx_ExpenseDate` exibida como "Expense Date" está certa — é o mesmo nome escrito para leitores diferentes. Já `gmx_ExpenseReportID2` exibida como "Expense Report ID" diverge de verdade.

## Por que importa

Quem lê o formulário e quem lê a fórmula veem nomes diferentes, e ligar um ao outro passa a depender de abrir o esquema da tabela.

O caso do sufixo numérico é o mais comum e o mais revelador: um `ID2` no esquema com "Expense Report ID" na tela costuma significar que a coluna foi criada, apagada e recriada, e o Dataverse desambiguou o nome sozinho. A coluna funciona, mas o nome guarda a cicatriz — e a próxima pessoa a procurar `gmx_ExpenseReportID` não vai encontrá-la.

Severidade informativa: não quebra nada, mas custa tempo de quem mantém.

## Exemplo

Ruim:

```
esquema: gmx_ExpenseReportID2
exibição: Expense Report ID
```

Bom:

```
esquema: gmx_ExpenseReportId
exibição: Expense Report ID
```

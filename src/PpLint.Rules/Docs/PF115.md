# PF115 — Dupla negação

## O que pega

`Not(Not(x))`, ou `!!x`, que equivalem a `x`. Numa cadeia mais longa a regra fala uma vez só, no nó mais externo — é um problema, não três.

## Por que importa

Aparece quando alguém inverte uma condição durante uma refatoração, inverte de novo para compensar e não simplifica no fim. Cada negação obriga quem lê a inverter mentalmente o significado.

## Exemplo

Ruim:

```
Not(Not(varAtivo))
```

Bom:

```
varAtivo
```

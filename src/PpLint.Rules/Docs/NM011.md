# NM011 — Prefixo do controle não corresponde ao tipo

## O que pega

Controle cujo prefixo contradiz o tipo real: um `toggle` chamado `btnAtivo`, um `label` chamado `txtNome`. A regra lê o template do controle no artefato — não adivinha o tipo pelo nome.

## Por que importa

Prefixo errado é pior que prefixo nenhum. Quem lê `btnAtivo` numa fórmula assume um botão e procura `OnSelect`; mas aquilo é um toggle, com `OnCheck`, `OnUncheck` e `Value`. O nome mente sobre o contrato do controle, e a mentira só aparece quando alguém tenta usá-lo.

## Exemplo

Ruim, para um controle do tipo `toggle`:

```
btnAtivo
```

Bom:

```
tglAtivo
```

## Como configurar

O mapa de prefixos vem do preset. Para ajustar um tipo:

```toml
[pp-lint.naming.control-prefixes]
toggle = "tog"
```

Presets disponíveis: `camel-prefix` (padrão) e `pascal-type`, que espera `ButtonSalvar` em vez de `btnSalvar`.

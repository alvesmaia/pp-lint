# PF114 — Ramo inalcançável

## O que pega

A mesma condição testada de novo depois de já ter falhado — na forma aninhada `If(c, a, If(c, b, d))` ou na encadeada `If(c, a, c, b, d)`, que são o mesmo desvio escrito de dois jeitos.

Condições voláteis ficam de fora: `Rand() > 0.5` testado duas vezes pode dar respostas diferentes, e aí o segundo ramo é alcançável de verdade.

## Por que importa

Se a condição era falsa para o fluxo chegar ali, ela continua falsa: aquele ramo nunca executa. O valor que alguém escreveu ali nunca chega ao usuário, e o comportamento real do app é diferente do que a fórmula aparenta.

## Exemplo

Ruim:

```
If(varTipo = "A", 1, If(varTipo = "A", 2, 3))
```

Bom:

```
If(varTipo = "A", 1, 3)
```

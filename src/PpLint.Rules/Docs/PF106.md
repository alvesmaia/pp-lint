# PF106 — `Set` redundante

## O que pega

Duas atribuições seguidas à mesma variável no mesmo bloco, sem nenhuma leitura entre elas e sem desvio entre elas. A regra não atravessa ramos de `If`: atribuir em ramos diferentes é justamente o uso correto.

## Por que importa

A primeira atribuição não tem efeito nenhum — o valor é sobrescrito antes de qualquer um poder lê-lo. Ver duas atribuições seguidas sugere que uma delas deveria ser outra coisa: outra variável, ou um valor que deveria ter sido usado no meio.

## Exemplo

Ruim:

```
Set(varStatus, "Carregando"); Set(varStatus, "Pronto")
```

Bom:

```
Set(varStatus, "Pronto")
```

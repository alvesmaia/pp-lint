# PF125 — Texto literal num app que traduz

## O que pega

Texto exibido ao usuário — `Text`, `HintText`, `Tooltip`, `AccessibleLabel` — escrito direto na fórmula, **num app que já tem tabela de tradução**.

A regra fica calada em app sem tradução nenhuma. Ali o texto literal é a escolha certa, e avisar seria empurrar trabalho que ninguém pediu.

## Por que importa

Ela só fala quando alguém começou a traduzir e deixou textos para trás. É o pior estado possível: o usuário vê a tela meio traduzida, metade no idioma dele e metade no do desenvolvedor, o que parece descuido mesmo quando o resto do app é bom.

## Exemplo

Ruim, num app com a fonte `Translations`:

```
lblTitulo.Text = "Confirmar pedido"
```

Bom:

```
lblTitulo.Text = LookUp(Translations, Chave = "confirmar_pedido").Texto
```

## Como a regra sabe que o app traduz

Pela presença de uma fonte de dados cujo nome contém `translation`, `localization`, `resources`, `idioma`, `tradução` ou `labels`. É heurística: um app que traduz por outro caminho não será cobrado, e isso é preferível a cobrar todo app do mundo.

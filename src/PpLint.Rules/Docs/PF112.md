# PF112 — Comparação com `true` ou `false`

## O que pega

`x = true`, que é `x`, e `x = false`, que é `Not(x)` — mais as formas equivalentes com `<>`.

## Por que importa

A comparação não acrescenta informação, e ainda sugere que `x` talvez não seja booleano: quem lê para para pensar se aquilo tem um terceiro estado. Comparação entre dois literais não entra aqui — é condição constante, e cabe à PF110.

## Exemplo

Ruim:

```
If(tglAtivo.Value = true, Notify("ligado"))
```

Bom:

```
If(tglAtivo.Value, Notify("ligado"))
```

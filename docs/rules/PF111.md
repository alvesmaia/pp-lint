# PF111 — `If` que só devolve booleano

## O que pega

`If(cond, true, false)`, que é apenas `cond`, e `If(cond, false, true)`, que é `Not(cond)`.

## Por que importa

A forma longa esconde a intenção atrás de um desvio que não existe. Quem lê precisa acompanhar dois ramos para descobrir que o resultado é a própria condição.

## Exemplo

Ruim:

```
If(ThisItem.Id = 4, true, false)
```

Bom:

```
ThisItem.Id = 4
```

# PF117 — `CountRows(x) > 0` em vez de `!IsEmpty(x)`

## O que pega

Teste de existência escrito como contagem: `CountRows(x) > 0`, `CountRows(x) >= 1`, e as mesmas formas com os lados trocados.

## Por que importa

`CountRows` percorre a coleção inteira só para saber se existe algum item; `!IsEmpty` para no primeiro. Sobre fonte grande a diferença aparece na tela do usuário, como atraso na abertura ou na rolagem.

## Exemplo

Ruim:

```
If(CountRows(colItens) > 0, Navigate(scrLista))
```

Bom:

```
If(!IsEmpty(colItens), Navigate(scrLista))
```

# NM012 — Tela fora do padrão de nome

## O que pega

Tela cujo nome não segue o padrão do preset ativo — no `camel-prefix`, o prefixo `scr` seguido de maiúscula.

## Por que importa

O nome da tela aparece em todo `Navigate` do app, e é o que alguém lê para saber para onde o botão leva. Uma tela chamada `Tela1` ou `Home` não diz se é a inicial, um diálogo ou um passo de assistente.

Nome com espaço tem problema adicional e mais sério, tratado pela NM040: ele obriga aspas simples em toda referência.

## Exemplo

Ruim:

```
Navigate(Home, ScreenTransition.Fade)
```

Bom:

```
Navigate(scrHome, ScreenTransition.Fade)
```

## Como configurar

```toml
[pp-lint.naming]
screen = "^Screen[A-Z][A-Za-z0-9]*$"
```

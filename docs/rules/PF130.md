# PF130 — A fórmula não compila

## O que pega

Propriedade cuja fórmula o parser do Power Fx recusa.

## Por que importa

Duas razões, e a segunda é a que justifica a severidade Erro.

A primeira é óbvia: uma fórmula que não compila não faz o que deveria.

A segunda é sobre esta análise. **Toda regra de Power Fx do pp-lint pula fórmulas que não compilam** — sem árvore não há o que examinar. Um achado PF130 significa que aquele trecho passou por fora de todas as outras regras, e o silêncio delas ali não é sinal de que está tudo bem.

## Exemplo

Ruim:

```
Set(varX,
```

Bom:

```
Set(varX, 1)
```

## Se a fórmula funciona no Studio

Pode acontecer: o pp-lint analisa com o parser público do Power Fx, que ocasionalmente fica atrás do Studio em construções muito novas. Se a fórmula funciona no app publicado, é caso de suprimir a regra naquele ponto e, se puder, abrir uma questão no repositório com o trecho — o parser é atualizado.

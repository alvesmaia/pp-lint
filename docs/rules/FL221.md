# FL221 — Consulta sem limite de linhas

## O que pega

Operação que lista registros sem o parâmetro `$top`.

## Por que importa

Enquanto a tabela é pequena não faz diferença nenhuma. O problema é que ela cresce, e o fluxo passa a percorrer tudo a cada execução **sem que ninguém tenha mudado nada** — o mesmo fluxo que rodava em segundos começa a levar minutos, e não há commit que explique.

Declarar quantas linhas o fluxo precisa também documenta a intenção: quem lê descobre que aquele passo espera dez registros, não dez mil.

O aviso é informativo porque nem toda consulta deve ser limitada — às vezes o fluxo precisa mesmo de tudo. O que a regra pede é que isso seja uma decisão.

## Exemplo

Ruim:

```json
"parameters": { "entityName": "contatos", "$filter": "statecode eq 0" }
```

Bom:

```json
"parameters": { "entityName": "contatos", "$filter": "statecode eq 0", "$top": 100 }
```

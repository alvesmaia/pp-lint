# PF122 — `ForAll` que escreve item a item

## O que pega

`ForAll` com `Collect`, `Patch`, `Remove`, `Update` ou `UpdateIf` dentro.

## Por que importa

Cada volta do laço é uma ida à rede. Com trezentos registros, são trezentas chamadas — o app trava por minutos, e o limite de requisições da licença aparece antes do fim.

`Collect` e `Patch` aceitam uma tabela inteira de uma vez, numa chamada só.

## Exemplo

Ruim:

```
ForAll(colNovos, Patch(Pedidos, Defaults(Pedidos), {Titulo: Titulo, Valor: Valor}))
```

Bom:

```
Patch(Pedidos, ForAll(colNovos, {Titulo: Titulo, Valor: Valor}))
```

O `ForAll` passa a só montar a tabela; a escrita acontece uma vez.

# PF105 — Variável global que poderia ser de contexto

## O que pega

Variável global definida com `Set()` que é lida em uma tela só.

## Por que importa

Global é estado do app inteiro: qualquer tela pode lê-la e qualquer tela pode alterá-la. Quando o uso real é de uma tela só, trocar por `UpdateContext` deixa o alcance explícito e impede que outra tela passe a depender dela por acidente — o tipo de acoplamento que aparece meses depois, quando alguém muda o valor num lugar e quebra outro.

Severidade informativa: não é defeito, é oportunidade de restringir o alcance.

## Exemplo

Ruim, com `varFiltro` lida apenas em `scrPedidos`:

```
Set(varFiltro, "Aberto")
```

Bom:

```
UpdateContext({locFiltro: "Aberto"})
```

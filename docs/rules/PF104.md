# PF104 — Nome não resolvido

## O que pega

Identificador usado numa fórmula que não corresponde a controle, variável, coleção, fonte de dados, parâmetro de escopo, função do Power Fx nem palavra reservada.

## Por que importa

Em Power Fx um nome desconhecido nem sempre quebra o app: em muitos contextos ele simplesmente vira branco. Um erro de digitação não impede a publicação — só faz o campo aparecer vazio para o usuário, e ninguém relaciona isso à letra a mais.

É por isso que esta regra tem severidade Erro.

## Exemplo

Ruim:

```
Set(varTotal, ValorTotall)
```

Bom:

```
Set(varTotal, ValorTotal)
```

# PF123 — Expressão aninhada demais

## O que pega

Fórmula com mais de seis níveis de chamadas dentro de chamadas.

Operadores e parênteses não contam. `((a + b) * (c - d))` aninha a árvore sem aumentar o que custa ler; o que pesa é `f(g(h(i(...))))`.

## Por que importa

Não é limite técnico — o Power Fx aceita muito mais. É limite de manutenção: quem for alterar a fórmula precisa segurar todos os níveis na cabeça ao mesmo tempo, e o erro típico é mexer no parêntese errado.

## Exemplo

Ruim:

```
Left(Right(Trim(Upper(Lower(Substitute(Text(varData), "a", "b")))), 3), 2)
```

Bom:

```
With(
    { texto: Substitute(Text(varData), "a", "b") },
    Left(Right(Trim(Upper(Lower(texto))), 3), 2)
)
```

`With` nomeia o passo intermediário, e cada linha passa a ser legível sozinha.

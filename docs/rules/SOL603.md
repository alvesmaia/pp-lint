# SOL603 — Solução managed em análise

## O que pega

Solução exportada como managed.

## Por que importa

Managed é o pacote de distribuição, não a fonte. Os achados apontam para código que você não pode editar naquele ambiente: o Studio abre os componentes em modo leitura, e a correção precisa acontecer na solução unmanaged do ambiente de desenvolvimento.

O aviso é informativo e serve para poupar a viagem: vale conferir se o artefato em mãos é o certo antes de trabalhar sobre a lista de achados.

## Exemplo

Ruim: analisar `MinhaSolucao_managed.zip` exportado de produção.

Bom: analisar a solução unmanaged do ambiente de desenvolvimento, que é onde as correções cabem.
